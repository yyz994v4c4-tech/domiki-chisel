# Домики чисел

Игра для изучения состава чисел от 1 до 10, сложения, вычитания и сравнения. Все задания и картинки находятся в файлах игры.

## Публикация

Загрузите файлы этой папки в корень публичного репозитория GitHub. В Settings → Pages выберите Deploy from a branch → main → /(root) → Save. После завершения публикации откройте адрес, указанный в Pages.

## Игра без интернета на iPad

Откройте игру в Safari, добавьте на экран «Домой», откройте с новой иконки при включённом интернете. Нажмите ⚙ → «Сохранить для игры без интернета». Дождитесь подтверждения, отключите интернет, закройте игру и откройте повторно для проверки. Озвучка зависит от голосов устройства.
